# 一分钟操作演示

形式：6张实际网页操作截图，每张10秒，画面内中文步骤说明和独立VTT字幕，无音轨。视频是操作截图讲解，不伪装成实时麦当劳业务调用。画面、餐品、门店、价格和券均为合成示例，不包含真实账户内容。本机语音服务未生成可用音频，因此不附带旁白。

| 时间 | 画面 | 画面文案 |
|---|---|---|
| 00–10秒 | 试玩首页 | 三十元，这餐怎么选得更明白？麦麦点餐参谋是一个开源点餐技能。这里全部使用合成数据，不需要登录或密钥。 |
| 10–20秒 | 预算、偏好与选店 | 先设置预算、口味和排除项，再主动选择一家演示门店。真实使用时，门店也需要由你确认。 |
| 20–30秒 | 推荐卡与餐单比较 | 最多比较三种不同餐单。最低实付和更合口味分别标注，预算之外的餐单不会进入推荐。 |
| 30–40秒 | 券体检 | 券体检区分持有、门店可用和餐单适用。比较完全相同餐单的带券和无券报价，才能确认用券收益。 |
| 40–50秒 | 局部改餐结果 | 保留汉堡，把玉米换成薯条。模拟重算给出新的示例整单价，原预算和排除项仍然保留。 |
| 50–60秒 | 复制修改需求与真实使用入口 | 复制需求，回到已经连接麦当劳官方接口的聊天，查询真实价格。项目已经开源，欢迎试用并留下反馈。 |

真实只读查询的证据与局限记录在 `VALIDATION.md`，不与本视频的合成演示混用。视频不包含下单或领券。
