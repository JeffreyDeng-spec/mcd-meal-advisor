## 真实 MCP 联调

使用客户端已有原生麦当劳 MCP，无额外模型密钥。搜索“上海市／人民广场”，在返回的营业门店中使用华旭国际大厦餐厅作为计划指定的验收门店；该门店选择不作为正式用户会话的默认选择。

- 门店：麦当劳上海黄浦华旭国际大厦餐厅，西藏中路336号。
- 需求：预算35元，一个鸡肉汉堡、一份薯条或玉米、一杯饮料；偏好无糖，不额外加购。
- 主轮快照：13:16:46；有效报价记录时间：13:17:45–13:20:37。
- 主轮保存16份成功报价、1份未确认返回的失败，3份候选未核价。20次核价预算包含联调期间重复的工具调用；未确认返回不自动重放。报价记录比调用次数少，不把调用次数冒充独立方案数。
- 本轮最低实付：Hold不住鸡排堡（椒盐风味）＋中薯条＋无糖可口可乐中杯，2290分。它同时匹配无糖偏好，因此合并标签。
- 带券对照：麦辣鸡腿汉堡＋中薯条＋小杯雪碧，完全一致的购买结构无券4550分、带券3490分，已验证券收益1060分。这不是与2290分套餐的差价。
- 改餐：麦香鸡中套餐保留麦香鸡和中薯条，仅将可乐中杯替换为该轮真实可选的无糖可乐中杯。新 run 初始无报价；重新调用 `calculate-price` 得到2800分。原预算和份数要求保留。
- 当前账户确有持券，真实核验了一个适用券分支；其他券不凭名称推断价值。离线数据另外覆盖过期券、不可用券、无券和未知收益。

实际使用的原生工具只有 `now-time-info`、`query-nearby-stores`、`query-meals`、`query-meal-detail`、`query-store-coupons`、`query-my-coupons`、`calculate-price`。未调用下单、取消、领券或积分兑换工具。原始响应和报告留在忽略的 `.local/`，不加入发布包。以上是验收当时结果，不是持续有效售价。

## 独立会话验证

安装后使用独立、无主对话历史的评估会话，明确加载安装目录的技能，复用原始查询材料且自行核价、生成报告。

第一次限制为4次核价，4次均成功，但发现同价套餐按指纹排队导致无糖候选偏后、零偏好匹配仍标“更合口味”、其他有效报价不能进入比较区。已据此修改候选顺序、标签条件和比较范围，并加入回归测试。

独立复验新主轮4次及修改轮1次，5次均成功。前两次已覆盖无糖偏好：2290分套餐和2800分麦香鸡套餐；把后者中薯换成官方可选的小杯玉米后新核价2750分，保留汉堡、饮料、35元预算与完整要求。复验仍未核价券分支，报告正确显示未知收益；券对照由上面的主联调验证。

独立评估两轮合计只调用 now-time-info 2次、query-meal-detail 1次、calculate-price 9次，均为只读。该验证证明明确加载后能完成对话工作流，不等同桌面客户端自动发现、WorkBuddy导入或人工选择门店界面的验收。
