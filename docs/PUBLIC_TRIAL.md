# 在线试玩与本轮验收

## 公开试玩

线上地址：https://jeffreydeng-spec.github.io/mcd-meal-advisor/

这是纯静态的合成数据试玩，包含预算、偏好、显式选店、餐单比较、券体检、模拟换餐、过期与重置、复制真实使用需求。任意自然语言及真实报价仍在已连接官方 MCP 的聊天中处理，不宣称网页理解任意请求或已调用真实业务接口。

演示时钟只允许重置 `mode=demo` 的数据；真实报价报告的15分钟展示策略没有改变。公开构建不读取真实运行目录，按显式文件清单复制。视频使用实际网页的6张操作截图和画面内中文字幕，无音轨，不伪装成实时业务录屏。

## 安全检查

- 页面不接收 Key、手机号或券码，不接入真实账户，不调用任何业务API。
- CSP 限制为本域脚本、样式、图片与媒体，`connect-src 'none'`，禁用对象、表单提交和 base URL。
- 无分析SDK、第三方字体、外部脚本、Cookie或本地持久存储。所有动态文本使用 textContent。
- 构建器拒绝非空输出目录，不把 `.local`、环境文件、Git元数据或原始响应放入网站。分享只使用固定公开URL和公开项目简介。
- 仓库已开启私密漏洞报告。未对麦当劳或其他第三方系统做漏洞测试；不承诺“零漏洞”。

## 浏览器验收

在本地 HTTP 预览验证：未选门店时拒绝生成；30元显示两种不同推荐；18元显示0.90元缺口；比较区展示餐品差异和整单差价；保留汉堡换薯条得到20.90元的合成示例；复制按钮显示成功；过期隐藏推荐并提示重查；换店立即清空旧方案。390像素窄屏无横向溢出，1280像素宽屏已检查。

## 本轮真实只读验收

2026-10-19，在当前会话按已安装技能执行完整查询与核价流程。技能已在客户端可用技能列表中出现；本记录不伪造用户本人操作或新的独立人工会话。

人民广场搜索返回营业门店；代理为验收选择华旭国际大厦餐厅，不作为用户正式点餐的默认门店。需求为单人即时到店自取、30元、鸡肉汉堡一份及薯条或玉米一份、排除饮料、不额外加购。

重新查询菜单、4份详情、门店券和完整券包后，主轮6次官方核价全部成功。麦辣鸡腿汉堡＋小玉米杯同购买结构无券3550分、带券2490分，验证券收益1060分。保留汉堡、把玉米换中薯的新轮初始不带旧报价，2次核价均成功，无券3600分、带券2540分。预算、份数、排除项完整保留。

实际工具仅为 now-time-info、query-nearby-stores、query-meals、query-meal-detail、query-store-coupons、query-my-coupons、calculate-price；未下单、领券、取消或兑换。原始记录与本地报告位于忽略的 `.local/growth-trial/`，不公开上传。公开页面、分享卡和视频全部使用另外生成的合成数据。

自动测试：57项 Python 测试通过，原报告与新试玩的 JavaScript 测试通过。新增覆盖合成时钟拒绝真实数据、预算输入、换餐保留主体、引擎嵌入、部署文件清单与原始券码排除。
