# 麦麦点餐参谋

复用宿主 AI 理解自然语言，调用宿主已配置的麦当劳原生 MCP。Python 3.9+ 脚本只读写本地 JSON 和 HTML，不联网、不读取 Token。不需要新增模型密钥。

## 开始与边界

- 本版仅支持单人、同一门店、现在到店自取（`beType=1, orderType=1`，不传 `beCode` 和预约时间）。遇到外送、多人或预约请求先说明范围。
- 只调用 `now-time-info`、`query-nearby-stores`、`query-meals`、`query-meal-detail`、`query-store-coupons`、`query-my-coupons`、`calculate-price`。即使用户让你下单、领券或兑换，本技能也只提供建议，不调用账户写工具。
- Token 由宿主 MCP 私有配置提供。不要读取、打印、请求用户在聊天中发送，或复制到项目、报告和 CI。原始 MCP 响应与运行 JSON 保存在当前项目 `.local/`，文件权限 600，不公开上传。

## 工作流程

1. 确认预算（元转为整数分）、必选餐品/份数、排除项、偏好和是否允许额外加购。默认不加购。名称/类别含义不清先问，不把未经证实的“低卡/无过敏原/不辣”当事实。把自然语言映射到当前菜单可证实的商品名、类别或用户确认的 code；同组 `terms` 是“任一匹配”，不同 `required` 组分别消耗餐品份数。
2. 没有门店时用用户提供的城市和商圈调用 `query-nearby-stores(searchType=2, beType=1)`；也可应用户要求查收藏。展示实际门店名称和地址并让用户选择，不能默认把验收门店当用户门店。仅展示即时取餐所需信息；用户询问预约时转出本版范围。
3. 对选定门店读取菜单、门店券与当前券包（券包按返回的 `totalPages` 获取，最多 5 页，合并 coupons 并保留完整性标记）。调用 `now-time-info` 取得北京时间。当前客户端工具签名优先于旧文档。保留完整原始工具结果，优先 `structuredContent`，不重新编造金额或响应。
4. 根据需求选至多 12 个相关单品/套餐查询详情；必须取得套餐的真实轮次和可选项。门店券引用菜单外商品时，先查详情并向用户说明目前尚不支持该商品池路径，不自行伪造菜单项。此版本只为已取得详情的菜单商品生成候选。
5. 按 [references/workflow.md](references/workflow.md) 写本轮 bundle，运行 `python3 <技能目录>/scripts/advisor.py prepare --input .local/bundle.json --output .local/run.json`。脚本会生成单点、套餐、单轮替换及单券候选；缺少相关详情而没有方案时，补查详情后重新 prepare，不把“不完整搜索”说成“没有餐可买”。
6. 逐次运行 `next --run .local/run.json`，仅对返回的 `calculate-price` arguments 原样调用宿主原生工具，再以完整原始响应文件调用 `record`。在调用前预留名额；一轮含对照最多 20 次，不自行绕开计数。`next` 返回 null 即结束。超时/限流/不完整响应记录失败，不自动重试；保留其他有效报价，让用户决定是否新开一轮。
7. 运行 `report --run .local/run.json --output .local/meal-report.html`。展示报告绝对路径及少量摘要：推荐金额、组成、预算余额、差价和券是否真适用。只把本轮已核价的合格方案称为推荐，不承诺全菜单最低价。没有预算内方案时显示最接近有效方案的超额，不偷偷加预算。
8. 用户说“换掉薯条、保留汉堡”时，先锁定本轮/方案和具体替代项。查询替代商品详情，更新本轮私有快照；新增预算、排除项、门店时重新 prepare。仅换餐用 `revise` 创建新 run，完整保留原要求，再 next → 官方核价 → record → 新报告。旧价格不能加减拼出新价格。父报告不覆盖，便于回看。

## 推荐与解释

硬要求先于任何排序。最多三种不同餐单：最低实付、偏好匹配、用券参考。相同内容的买法保留便宜者并合并标签。偏好或用券方案更贵时明确多花多少，快到期不能成为超预算或强迫加购的理由。

券包持有、门店可用、本餐单适用是三个状态。只按实际 ID/券码关联，不按同名券猜测身份；有效期、时段限制原样展示。用券收益只比较完全相同购买结构的带券/不带券官方报价；套餐替换价差另列，不重复相加。无法确定的数值显示未知，券过期不等于现金损失。

网页调整预算只筛已有报价；网页不联网。复制的修改请求回到对话后才能重新查询。报告过期保留记录并提示重新核价，不能冒充当前售价。

## 安装与演示

完整复制本目录到客户端技能目录，再在新会话明确调用 `mcd-meal-advisor`。例如本机技能目录为 `~/.agents/skills/`；其他宿主用各自导入入口。先在客户端配置麦当劳官方 MCP，本技能不复制连接凭证。

未连接 MCP 时运行 `python3 <本技能目录>/scripts/demo.py --output .local/demo.html`，直接打开生成的单文件报告。演示器随技能分发，全部为明确标注的合成数据，无第三方依赖；不能把演示报价、ID 或门店传给真实 MCP。仓库另有 `examples/demo.py` 入口及完整测试。
