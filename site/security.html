公开试玩

本站只包含明确标注的合成数据，不读取账户，不连接麦当劳业务接口，不接收或保存 Token、手机号和券码。输入在浏览器内存中处理，不使用分析脚本、Cookie或本地持久存储。GitHub Pages 等基础设施可能记录访问日志，适用其自身隐私政策。

真实使用

真实查询在你自己的 AI 客户端中通过官方 MCP 进行。凭证仅配置在客户端私有设置中；本项目的计算脚本不读取凭证。原始业务响应存放在忽略的私有目录，不应公开分享。

发布内容

站点采用显式文件清单部署。公开产物不包含真实运行目录、环境文件、Git元数据或原始账户响应。页面禁止业务网络连接，并只加载本域脚本和媒体。

问题反馈

普通使用问题可提交脱敏 GitHub Issue。疑似安全问题请使用仓库 Security 页的私密报告入口，避免在公开评论中贴出密钥、私人信息或可直接利用的细节。本说明不代表对任何软件作“零漏洞”保证。
